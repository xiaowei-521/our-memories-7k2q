# 💝 网页表白惊喜 — 使用说明

## 怎么打开
双击 `index.html`，用浏览器（Edge / Chrome / 手机浏览器都行）打开即可，不需要联网、不需要装任何东西。

## ⚠️ 送出去之前，先改这几处
用记事本或 VS Code 打开 `index.html`，找到顶部的 `CONFIG` 区域：

| 要改的 | 说明 |
|---|---|
| `herName` | 她的昵称（会出现在开场和提问里） |
| `startDate` | **⚠️ 必改**：你们认识/在一起的日子，用来算「认识你的第 N 天」 |
| `letter` | 信的内容，一行一个引号项，随便增删改 |
| `photos` | 回忆相册：`src` 填图片文件名（和 index.html 放同一文件夹），`tag` 是胶带上的小字，`caption` 是照片下的手写注释；想加第三张就照样子多加一行 |
| `portraits` | 「每一个阶段的你」人像画廊：自动轮播 + 手写注释，顺序和文案都在这里改 |
| `sign` | 最后的落款签名 |

改完保存（保持 UTF-8 编码，记事本默认就是）。

## 背景音乐
已就位：《告白气球》`bgm.flac`（47MB，FLAC 格式现代浏览器都支持）。她点「轻轻点开」后自动循环播放。想换歌就把新文件改名为 `bgm.flac` 覆盖，或改 `index.html` 顶部 CONFIG 里的 `bgm` 文件名。

## 怎么送给她
- **当面**（效果最好）：电脑/手机打开，递到她手里。
- **异地**：
  1. 把 `index.html`（和 `bgm.mp3`）一起压缩成 zip 发给她，她解压后双击打开（微信直接发文件会被改名或拦截，**记得压 zip**）；
  2. 或者免费部署成网页链接（GitHub Pages / Vercel），发链接最顺滑。

## 藏了哪些彩蛋
- 📸 点开信封后是「回忆相册」：照片做成手写注释的卡片叠成一摞，点一下就飞走并炸开一串爱心
- 🔍 每张卡片右上角有放大镜按钮，点开可以看大图；再点图片还能放大到原图尺寸，长截图可上下滑动细看（点背景、✕ 或按 Esc 关闭）
- 🌸 相册翻完进入「每一个阶段的你」人像画廊：自动放映她的每一面，左右箭头/滑动可手动翻，点照片可放大
- 🖱️ 整个页面随便点，点哪儿哪儿开出一朵爱心；鼠标划过会拖出一串小爱心
- 🏃 「让我想想」按钮会逃跑 + 越缩越小，追 7 次后直接认命消失
- 🎆 点「我愿意 ❤」放爱心烟花，并记住这一刻（只记第一次，重温不清零）
- 💞 她答应之后再打开这个页面，会直接显示「我们已经在一起 X 天 X 小时 X 分 X 秒」的实时纪念页
- ↺ 纪念页右下角可以「重温这一刻」再放一遍

## ⚠️ 发文件给别人时
`index.html`、所有照片（图1~图4.jpg、人像1~人像8.jpg）和 `bgm.flac` **必须打包在一起**（压成 zip），少一张照片就少一段回忆。另外图3/图4 的小票上有手机号，如果打算把页面发布成公开链接分享，记得先考虑要不要给小票打个码。
